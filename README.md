# Blur Detection using MLP

## 📊 Overview
This project focuses on detecting blurred images using machine learning techniques.

The model is trained to classify images into blurred and non-blurred categories based on extracted features.

---

## 🚀 Results
- Accuracy: 94%
- Dataset size: 1050 images

---

## 🛠 Technologies Used
- Python
- OpenCV
- Scikit-learn

---

## ⚙️ Methodology
- Extracted handcrafted features from images
- Trained a Multi-Layer Perceptron (MLP) model
- Evaluated model performance using accuracy
